# FB Trim — Minimal Sidebar

A sleek, ultra-lightweight Chrome extension that declutters Facebook by trimming unwanted left sidebar icons and navigation buttons.

## Features
- **Ultra-Lightweight & Fast**: Injected at `document_start` for instantaneous CSS hiding with zero layout shift (FOUC).
- **19 Left Sidebar Toggles**: Customize every icon in Facebook's left navigation (Profile, Friends, Feeds, Groups, Marketplace, Reels, Memories, Saved, Pages, Events, Gaming, Meta AI, Ads Manager, Recent Ad Activity, Professional Dashboard, Messenger Kids, Meta Quest, Fundraisers, Orders & Payments).
- **Top Navigation Toggles**: Hide Reels, Marketplace, and Gaming from the top header.
- **Curated Defaults**: Pre-configured to trim clutter while preserving essential daily tools.
- **Quick Actions**: One-click "Restore Recommended", "Hide All", and "Show All" controls.

## Installation
1. Clone or download this repository.
2. Open `chrome://extensions` in Chrome.
3. Enable **Developer mode** in the top right.
4. Click **Load unpacked** and select this directory.
